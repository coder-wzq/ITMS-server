## 项目结构

```
ITMS-server/
├── cmd/
│   ├── gateway/main.go             # Gateway 入口
│   └── integration_test/main.go    # 集成测试
├── pkg/                            # 共享库
│   ├── config/config.go            # YAML配置加载(env覆盖+fsnotify热加载)
│   ├── db/
│   │   ├── base_model.go           # BaseModel(ID/CreatedAt/UpdatedAt/DeletedAt)
│   │   ├── snowflake.go            # Snowflake ID生成器
│   │   ├── postgres.go             # GORM连接(池MaxOpen=100,MaxIdle=25,Lifetime=5min)
│   │   └── scope.go                # 软删除全局Scope
│   ├── etcd/register.go            # Etcd注册(自动注册+心跳TTL=10s/续约3s)
│   ├── jwt/jwt.go                  # JWT(HS256,accessToken=2h,refreshToken=7d)
│   ├── middleware/
│   │   ├── cors.go                 # CORS中间件
│   │   ├── jwt.go                  # JWT认证中间件(排除login/refresh)
│   │   ├── logger.go               # 请求日志中间件
│   │   ├── operation_log.go        # 操作日志(POST/PUT/DELETE+脱敏+异步)
│   │   ├── ratelimit.go            # 令牌桶限流
│   │   └── recovery.go             # Panic Recovery
│   ├── redis/
│   │   ├── client.go               # go-redis/v9 封装(Set/Get/Del/HSet/Incr/PubSub)
│   │   └── keys.go                 # Key命名规范+TTL常量
│   └── response/
│       ├── errcode.go              # 完整错误码体系(00000~15xxx)
│       ├── http_status.go          # 错误码→HTTP状态码映射
│       └── response.go             # 统一响应{code,message,data,requestId}+分页
├── services/                       # 15个微服务
│   ├── svc-auth/                   # CSCI-01 认证授权
│   ├── svc-user/                   # CSCI-02 用户管理
│   ├── svc-config/                 # CSCI-03 系统配置

│   ├── svc-task/                   # CSCI-05 任务管理
│   ├── svc-planning/               # CSCI-06 任务筹划

│   ├── svc-sim-proxy/              # CSCI-08 仿真代理网关
│   ├── svc-situation/              # CSCI-09 二三维态势
│   ├── svc-voice/                  # CSCI-10 话音管理
│   ├── svc-dict/                   # CSCI-11 数据字典
│   ├── svc-agent/                  # CSCI-12 智能体
│   ├── svc-report/                 # CSCI-13 分析报告
│   ├── svc-record/                 # CSCI-14 训练记录
│   └── svc-admin/                  # 后台管理
├── api/gateway.api                 # Gateway路由定义
├── migrations/
│   ├── 000001_init_schemas.up.sql  # 创建14个Schema
│   ├── 000001_init_schemas.down.sql

│   ├── nginx/nginx.conf            # Nginx反向代理(/api/*,/ws/*)
```
